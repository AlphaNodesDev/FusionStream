## 🚀 Features

- 🔎 **Multi-provider Search**  
  Seamless switching between multiple content sources (Anime, TV, Movies).

- 🧩 **Modular Extension Support**  
  Add and manage content sources easily with a future-ready extension system.

- 📁 **Dynamic Catalog Loading**  
  On-demand content loading from your selected provider with smooth rendering.

- 🌐 **Open Source Friendly**  
  All data and provider logic is open and customizable for community development.
